# Подменённый EDID для HDMI

Обход для случая, когда телевизор или монитор подключён по HDMI, но система его не видит,
потому что не может прочитать его EDID — «паспорт» с поддерживаемыми разрешениями.
EDID передаётся по отдельным служебным линиям кабеля (DDC); если они повреждены, а сама
картинка по кабелю проходит, можно подсунуть ядру готовый EDID — и экран заработает.

`install.sh` эту папку **не** трогает: ставится только вручную и только там, где нужно.

## Когда ставить

Нужны **все** признаки сразу:

1. Кабель подключён, телевизор включён и стоит на нужном входе HDMI, но картинки нет —
   ни на рабочем столе, ни в `hyprctl monitors all`.
2. Выход числится отключённым:
   ```sh
   cat /sys/class/drm/card*-HDMI-A-1/status   # disconnected
   ```
3. В логе ядра есть ошибки чтения EDID именно на этом выходе (появляются при подключении кабеля):
   ```sh
   journalctl -k -b | grep -i edid
   # [drm:dm_helpers_read_local_edid [amdgpu]] *ERROR* EDID err: 2, on connector: HDMI-A-1
   # amdgpu ...: [drm] *ERROR* No EDID read.
   ```
4. Уже проверено, что дело не в простом: кабель переткнут с обеих сторон, пробовали другой
   порт HDMI на телевизоре и, если есть, другой кабель без переходников.

Если ошибок EDID в логе нет — проблема в другом, этот обход не поможет.

## Когда не ставить

- Экран и так определяется (`connected`) — ничего делать не надо.
- К этому выходу подключают разные мониторы или проектор. Подменённый EDID навязывает
  любому из них 1920x1080@60 вместо их настоящих режимов.
- Нужно разрешение выше 1920x1080 (4K-телевизор) — с этим EDID оно будет недоступно.
- Ошибка из‑за переходника или удлинителя, которые можно просто убрать.

## Проверить без перезагрузки

Из этой папки можно до установки убедиться, что картинка вообще пойдёт (действует до перезагрузки,
номер `dri/1` — тот же, что у `card1` в пункте 2):

```sh
D=/sys/kernel/debug/dri/1/HDMI-A-1
sudo sh -c "cat forced-1080p.bin > $D/edid_override; echo 1 > $D/trigger_hotplug"
cat /sys/class/drm/card1-HDMI-A-1/status    # должно стать connected
```

Телевизор показал рабочий стол — можно ставить насовсем. Нет — повреждена уже сама линия
видеосигнала, менять кабель или разъём.

## Установка и удаление

```sh
./install-edid.sh               # для HDMI-A-1
./install-edid.sh HDMI-A-2      # для другого выхода
./install-edid.sh --remove      # убрать, например после замены кабеля
```

Скрипт кладёт EDID в `/usr/lib/firmware/edid/`, добавляет его в `FILES=` в `/etc/mkinitcpio.conf`,
дописывает параметр `drm.edid_firmware=...` в `/etc/kernel/cmdline` (загрузка через UKI) или в
`GRUB_CMDLINE_LINUX_DEFAULT` (обычный GRUB) и пересобирает образ загрузки. Исходные файлы
сохраняются с суффиксом `.orig`. После установки — перезагрузка.

Звук по HDMI в этом EDID объявлен (стерео LPCM), но поддерживает ли его сам телевизор,
система узнать не может — проверяется на слух облаком звука на Waybar.

## Файлы

- `forced-1080p.bin` — EDID 1920x1080@60 (плюс 1280x720) со звуком по HDMI.
- `make_edid.py` — из чего он собран: `./make_edid.py > forced-1080p.bin`.
- `install-edid.sh` — установка и удаление.
